Lesson 7

Text & Shapes

Design posters and pub mats using text and shapes. Learn how to style and arrange elements cleanly.

Adding Text

Select the Type Tool (T) and click anywhere on the canvas to start typing. Each text block is automatically placed on its own layer. Use the Options Bar or the Character Panel (Window → Character) to adjust font, size, color, tracking, and leading.

Point Text vs. Paragraph Text

Point Text — Click once and type. The line grows as long as you type. Best for short headings or labels.

Paragraph Text — Click and drag to create a text box. Text wraps inside the box. Best for longer body copy.

💡

Tip: Double-click the T icon on a text layer in the Layers Panel to quickly re-enter editing mode for that text.

Styling Text

  • Change font family and weight in the Options Bar
  • Adjust tracking (letter spacing) and leading (line spacing) in the Character Panel
  • Apply layer styles (Drop Shadow, Stroke, Glow) via Layer → Layer Style
  • Warp text using the Warp Text button in the Options Bar for curved or arc effects

Drawing Shapes

Use the Shape Tools (U) to draw rectangles, ellipses, polygons, lines, and custom shapes. Shapes in Photoshop are vector-based, meaning they stay crisp at any size. You can fill them with solid colors, gradients, or patterns, and add strokes via the Options Bar.

⚠️

Remember: Rasterizing a text or shape layer converts it to pixels and makes it no longer editable as text or a vector. Avoid rasterizing unless absolutely necessary.
