Lesson 8

Smart Objects

Edit and resize images without losing quality — perfect for flexible, non-destructive designs.

What Is a Smart Object?

A Smart Object is a special type of layer that preserves the original content of an image or vector graphic. Unlike regular pixel layers, Smart Objects can be scaled, rotated, and transformed repeatedly without any loss of quality, because Photoshop always references the original source data.

How to Create a Smart Object

Right-click any layer in the Layers Panel and choose Convert to Smart Object. You'll see a small icon appear on the layer thumbnail indicating it's now a Smart Object. You can also place an image as a Smart Object directly via File → Place Embedded.

💡

Tip: Filters applied to a Smart Object become Smart Filters — they remain editable and can be turned on or off at any time.

Smart Filters

When you apply a filter (like Gaussian Blur or Sharpen) to a Smart Object, it becomes a Smart Filter. Smart Filters are non-destructive: you can double-click them to re-open the filter dialog and change the settings, or delete them entirely without affecting the original image.

Linked vs. Embedded Smart Objects

Embedded Smart Objects store the original file data inside the PSD. Linked Smart Objects reference an external file — if you update the source file, all linked instances update automatically. Linked Smart Objects are especially useful for maintaining consistent assets across multiple documents.

⚠️

Heads up: To paint directly on a Smart Object layer you must first rasterize it (right-click → Rasterize Layer), which removes the Smart Object benefits. Use a separate layer on top instead.
