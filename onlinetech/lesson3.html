Lesson 3

Basic Tools

Start creating using essential tools like move, brush, crop, and selection tools — your foundation for every design.

The Toolbox

The Toolbox is a vertical panel on the left side of the screen. It contains all of Photoshop's core tools, organized by category. You can access any tool by clicking it, or press its keyboard shortcut for faster switching.

Essential Tools to Know

  • Move Tool (V) — Moves layers or selected content around the canvas
  • Rectangular Marquee (M) — Selects a rectangular area of the image
  • Lasso Tool (L) — Draws freehand selections
  • Crop Tool (C) — Trims the canvas to a specific size or ratio
  • Brush Tool (B) — Paints on the canvas with customizable brushes
  • Eraser Tool (E) — Removes pixels from a layer
  • Zoom Tool (Z) — Zooms in and out of the canvas
💡

Shortcut tip: Press and hold a tool's shortcut key to temporarily switch to it, then release to go back to your previous tool.

Using the Move Tool

The Move Tool is one of the most used tools in Photoshop. Select it by pressing V, then click and drag any layer to reposition it. With the Auto-Select option enabled in the Options Bar, clicking directly on an object automatically selects its layer.

Cropping Your Canvas

The Crop Tool lets you resize your canvas by dragging handles around the image. You can set a fixed ratio (like 1:1 for a square) or enter custom dimensions in the Options Bar. Press Enter to apply the crop, or Escape to cancel.

⚠️

Watch out: The Eraser Tool permanently removes pixels. Use a Layer Mask instead if you want a non-destructive workflow.
